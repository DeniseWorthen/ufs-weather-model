\doxysubsection{Detailed Description}
Shared setup/teardown helpers for outputlog unit tests. 

Extracted from \doxylink{test__driver2_8F90}{test\+\_\+driver2.\+F90} (freqn test) so that restart-\/pairing -- and any future outputlog test needing the same real ESMF clock/alarm/ cf\+\_\+n/state\+\_\+n setup and fixture-\/file handling -- doesn\textquotesingle{}t duplicate this nontrivial setup by hand. Deliberately separate from \doxylink{namespacetest__utils}{test\+\_\+utils} (generic testing infrastructure -- esmf\+\_\+err/assert\+\_\+equal/testsummary)\+: these two routines are specific to the outputlog-\/testing domain, not generic utilities.
