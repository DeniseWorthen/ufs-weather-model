\doxysubsection{Detailed Description}
Test code for outputlog Alarm Initialization. 

Probes the use of Alarm\+Init from MOM6 NUOPC cap to intialize alarms for use by outputlog feature. Tests to ensure the outputlog alarms will trigger for start hours which are not multiples of 6 (eg IAU use cases)
