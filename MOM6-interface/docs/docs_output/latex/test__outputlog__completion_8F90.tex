Test code for the outputlog file-\/completion contract.

A test like this only has value if its notion of "{}correct"{} doesn\textquotesingle{}t come from the same place as the code being tested -- otherwise it just checks that the code agrees with itself. Two things keep this one independent\+:


\begin{DoxyEnumerate}
\item The fixtures are built with plain net\+CDF library calls (nf90\+\_\+create, nf90\+\_\+put\+\_\+var, nf90\+\_\+sync) -- never by calling file\+\_\+is\+\_\+complete or anything in \doxylink{namespacemom__outputlog__methods}{mom\+\_\+outputlog\+\_\+methods}. A second, separate confirmation of the same contract came from ncdump -\/c snapshots of real production files (a wholly different tool, sharing no code with either file\+\_\+is\+\_\+complete or these fixtures).
\end{DoxyEnumerate}

So the fixtures here aren\textquotesingle{}t constructed to match file\+\_\+is\+\_\+complete\textquotesingle{}s own logic -- they\textquotesingle{}re constructed to match a pattern established independently of it, twice over, and file\+\_\+is\+\_\+complete is checked against that.
