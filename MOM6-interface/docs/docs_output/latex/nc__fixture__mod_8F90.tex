\doxysubsection{Detailed Description}
Net\+CDF fixture to generate files with established behaviour of file creation and completion. This feature creates files and then writes files with one of two observed patterns\+: 

1) in DATM mode, nlen flips from 0 at creation to 1 at completion; file size is \texorpdfstring{$\sim$}{\string~}constant 2) in ATM mode, nlen\texorpdfstring{$>$}{>}0 at creation and completion is determined by the file size increase

For 1) we can\textquotesingle{}t reproduce the observed behaviour using a variable that actually shares "{}time"{} (writing any such variable immediately advances nlen) so this is a deliberate stand-\/in that reproduces the observable nlen/fsize progression without replicating the real file\textquotesingle{}s internal variable structure. file\+\_\+is\+\_\+complete/get\+\_\+file\+\_\+state only look at nlen and fsize, so that\textquotesingle{}s sufficient for what\textquotesingle{}s under test.
