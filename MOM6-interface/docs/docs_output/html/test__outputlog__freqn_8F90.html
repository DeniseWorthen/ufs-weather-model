Detailed Description

Orchestration test for the outputlog_freqn machinery.

Set up a modelClock and ring state for a logging frequency; calls into track_freqn with fixed curr/next Time, mimicking actual ModelAdvance where the clock itself never advances. Creates and completes files in same sequence as actual production code.
