Detailed Description

Shared setup/teardown helpers for outputlog unit tests.

Extracted from test_driver2.F90 (freqn test) so that restart-pairing – and any future outputlog test needing the same real ESMF clock/alarm/ cf_n/state_n setup and fixture-file handling – doesn't duplicate this nontrivial setup by hand. Deliberately separate from test_utils (generic testing infrastructure – esmf_err/assert_equal/testsummary): these two routines are specific to the outputlog-testing domain, not generic utilities.
