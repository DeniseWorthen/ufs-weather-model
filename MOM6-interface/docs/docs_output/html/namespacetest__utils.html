◆ grow_if_needed()

subroutine test_utils::grow_if_needed ( type(testsummary), intent(inout)  summary)
private

Grows teststatus/testmessage/errmessage to fit summarycount, doubling capacity (or matching count exactly if that's larger) rather than a fixed maxtests – add_test_result can never write out of bounds, and init(maxtests) becomes just an optional initial-capacity hint rather than a hard, easy-to-forget-to-update limit. Safe to call whether or not init() was ever called (an unallocated array is treated as size 0).
