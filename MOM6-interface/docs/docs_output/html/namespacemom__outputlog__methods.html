Compute the alarm-alignment toffset.

The time offset in hours (toffset) required to ensure that an output-frequency alarm rings on that frequency's own nominal grid, regardless of the actual (eg restart or IAU-shifted) start hour.

Parameters
[in]hourthe model's actual start hour (0-23)
[in]freqthe output frequency, in hours
Returns
the alignment offset, in hours
